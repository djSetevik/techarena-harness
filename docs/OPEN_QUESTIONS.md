# Открытые вопросы

Источники: R1 — [регламент](codex/materials/original/regulations.ru.md),
Q1 — [ответы 7 ноября](codex/materials/original/qa-2026-11-07.ru.md).
Рабочие решения ниже — проектные, не дополнительные правила организаторов.

| Вопрос | Противоречие или пробел | Статус |
|---|---|---|
| Модели | R1: четыре модели с -noreason и переключение; Q1: две для разработки, фиксированная при оценке | Уточнить финальную модель и способ передачи имени. Fixed сохранён по умолчанию; complexity — явная инженерная опция. Два API-пробника приняли оба имени Q1, но не устраняют конфликт финального регламента |
| openJiuwen | R1: любая версия, пример 0.1.19; Q1: последняя | Pin 0.1.19 и API подтверждены в контейнере настоящими SDK-тестами; допустимость именно этого релиза перед финалом требует сверки |
| CPU | R1: до 4 ядер, команда содержит 8 | Финальные лимиты не подтверждены |
| Сессии | R1: до 5; Q1: агентов сколько угодно | Различать агентов и конкурентные запросы; планировать concurrency=1 |
| Запуск и ответы | R1: OUT/общий файл и answer.txt; Q1: рядом с task.json, команда 9 ноября | Поддержан текущий CLI, только task_dir/answer.txt; финальная команда pending |
| Coding | Q1 ответил «рядом», не уточнив проверку исходников | Обе видимые coding-задачи решены live и повторно проверены в workers без сети/ключей; финальные разрешённые файлы/проверка и single-container credential policy требуют сверки |
| Локальные модели | R1 запрещает локальные нейросети; Q1 разрешает лицензированный код/модели | Не включать локальные нейросети до уточнения |
| Usage и исчерпание | Стоимость input/10 + output известна; исчерпание development proxy не провоцировалось | Разрешённый live qwen3.8-27b вернул input/output/reasoning; included-схема записана в отчёте, output600 включает reasoning355; формат quota/exhaustion ошибок ещё не проверен |
| Прогнозы | Q1 обещает будущую публикацию метрик | Формула и требуемые артефакты pending |
| oJ при deterministic решении | oJ обязателен, все задачи разрешено решать детерминированно | Уточнить достаточную содержательную интеграцию; текущий offline-прогон её не доказывает |

Решено: Codex разрешён для разработки по [U1](codex/materials/clarifications/codex-development-authorization.ru.md).
Это не разрешает Codex/API Codex в финальном runtime.
