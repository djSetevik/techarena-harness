## Не выполнялось

- Не запускался Codex в учётной записи пользователя.
- Не изменялся Git-репозиторий или VPS пользователя.
- Не было запросов к конкурсному прокси, live-LLM или регистрации/heartbeat.
- Не запускались coding-тесты и сгенерированный код задач.
- Не собирался заново Docker-образ; 1.36 GB в brief — ранее присланный пользователем результат.
- Feasibility Detector, BudgetManager и scheduler здесь описаны как задания, а не выданы за уже реализованные.

Скрипт verify_package.py проверяет контрольные суммы файлов пакета. После осознанного изменения документов его сообщения CHANGED ожидаемы.

## Проверка редакции v2 — разрешение Codex для разработки

Изменены инструкции и добавлено U1, основанное на сообщении владельца проекта.
Не проводилась новая проверка сайта или независимое подтверждение телефонного
разрешения. Старые ограничения runtime, секретов, expected и доступа сохранены.

Проверки этой редакции:
- Из рабочих инструкций удалены старые требования повторно согласовать Codex.
- AGENTS.md, стартовое задание и этапы учитывают U1.
- Исходные R1/Q1, task-dir.zip и baseline ZIP не изменены байт-в-байт.
- Подготовлен обновлятор для уже установленного пакета; синтаксис проверен.
- Обновление проверено на исходной версии, повторном запуске, пользовательских
  дополнениях вне заменяемых фрагментов и конфликте внутри фрагмента.
- Сохраняются резервные копии; при конфликте запись файлов не начинается.
- Контрольные суммы пересчитаны; verify_package.py и проверка ZIP проходят.

В ходе правки v2 не запускались Codex, конкурсные модели, Docker или SSH;
сервер и Git-репозиторий пользователя не изменялись. Отчёт прежних offline-тестов
выше не следует читать как повторный запуск харнесса при этой редакции.
